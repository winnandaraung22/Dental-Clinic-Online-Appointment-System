Overview

The dental clinic online appointment system is an Android Mobile Application developed to simplify dental appointment scheduling and improve communication between patients, dentists, and the clinic administrator.

Since this project is an academic project, all rights belong to the developer. Therefore, the dental clinic was named "GentleTouch Dental Clinic". The system allows patients to view available dentists, select appointment dates and times, submit appointment requests, receive appointment updates, and communicate with dentists through in-app messaging.

Features

Patient

- Register and log in securely
- Manage personal profile
- View dental services
- View available dentists and schedules
- Book dental appointments
- View appointment status
- Receive appointment notifications
- Chat with dentists
- Rate dentists

Dentist

- Log in through the staff access system
- View assigned appointments
- View patient appointment details
- Manage profile information
- Change password
- Communicate with appointment confirmed patients

Clinic Administrator

- Manage dentist accounts
- Manage dentist schedules
- View and manage appointment requests
- Approve or cancel appointments
- Send appointment updates to patients
- Communicate with dentists

Database

The system uses Firebase Firestore as its cloud-based NoSQL database.

Main collections include:

- users
- doctors
- doctorSchedules
- appointments
- notifications
- staff
- chats
- services
- ratings

User Roles

The system supports three main user roles:

- Patient
- Dentist
- Clinic Administrator

The system is developed for only one Administrator. No additional Clinic Administrator can be added.

Purpose

The project aims to reduce the limitations of manual appointment booking by providing a centralized mobile system for appointment scheduling, dentist availability management, notifications, and patient–dentist communication.
